## 🚀 Arquitecturas & Sistemas en Producción

<details open>
<summary><b>🚚 Rupay Analytics — Enterprise Data Warehouse & BI Platform</b></summary>
<br>

*Plataforma analítica desacoplada para optimización logística, rotación de stock y retención de clientes en la distribución de gas GLP (Lima, Perú).*

```
   [ FUENTES OPERATIVAS ]                 [ GOOGLE BIGQUERY DATA WAREHOUSE ]              [ CONSUMO & BI ]
┌─────────────────────────┐            ┌──────────────────────────────────────┐        ┌────────────────────┐
│ PostgreSQL Transaccional│            │ 🥉 BRONZE: Raw Lake / Ingesta Diaria │        │ Microsoft Power BI │
│ Hojas Operativas / CSVs │ ──(Python)─▶ 🥈 SILVER: dbt Core (Staging / PII)  │───────▶│  (DAX & KPIs)      │
│ Logs de Despacho        │            │ 🥇 GOLD:   Kimball Star (fact_orders)│        │ Looker Studio / API│
└─────────────────────────┘            └──────────────────────────────────────┘        └────────────────────┘
```

- **Ingeniería & Pipeline ELT** — Extractor modular en Python bajo arquitectura Hexagonal (*Ports & Adapters*), con carga incremental nocturna automatizada vía GitHub Actions (3:00 AM America/Lima).
- **Transformación con dbt Core** — Modelado Medallion en Google BigQuery con tipado estricto, normalización geográfica y seudonimización SHA-256 para protección estricta de datos (PII).
- **Gobernanza de Datos** — Rol de lectura analítica dedicado con políticas Row-Level Security (RLS) en PostgreSQL sobre tablas transaccionales.
- **Business Intelligence** — Tableros interactivos en Power BI para control de Churn, Customer Lifetime Value (LTV), rotación de envases por válvula/peso y optimización de tiempos de despacho logístico.

`Python` `dbt Core` `Google BigQuery` `PostgreSQL` `Power BI` `GitHub Actions`

> 🔒 *Sistema corporativo en producción diaria con datos protegidos bajo estricta confidencialidad. Demostración metodológica disponible en entrevistas técnicas.*

</details>

<details open>
<summary><b>📦 Delivery Core — Motor ERP & Logística de Distribución (DWY Solutions)</b></summary>
<br>

*Plataforma SaaS / ERP multisede diseñada para distribuidoras con operación de delivery intensivo, despacho multicanal y gestión de inventarios.*

- **Arquitectura de Software** — Backend desacoplado y modular con diseño orientado al dominio (DDD) y máquina de estados finita para transiciones de ciclo de vida de pedidos.
- **Modelado de Datos** — Base de datos relacional altamente normalizada en PostgreSQL con Prisma ORM, control de inventario de envases en comodato, asignación de choferes y cuadres de caja automáticos.
- **Integraciones** — Módulos de facturación electrónica bajo normativa SUNAT, pasarelas de pago y tracking operativo en tiempo real.

`Node.js` `Express` `TypeScript` `PostgreSQL 15` `Prisma ORM` `Docker` `BPMN`

> 🔒 *Plataforma SaaS en desarrollo y despliegue activo bajo la organización DWY-Solutions.*
